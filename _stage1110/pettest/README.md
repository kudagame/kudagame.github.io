# 蜜糖之家 寵物系統 測試版（第二期 P2）

這是獨立的寵物系統測試包，**不會動到主遊戲**。依據 `design/pet_system_zh.md` v6＋P2 實作（P2 規則見該文件「P2 更新紀錄」）。
測試版的資源給得很多，也附了開發者介面，方便測時間、機率和數值。

## 怎麼開

```bash
cd <遊戲專案根目錄>              # 也就是 pettest 的上一層
node pettest/tools/serve.mjs 18923
# 用瀏覽器打開 http://127.0.0.1:18923/pettest/
# 手機要在同一個網路上測的話：HOST=0.0.0.0 node pettest/tools/serve.mjs 18923，
# 然後在手機上開 http://<電腦 IP>:18923/pettest/
```

- 用 serve.mjs 開的時候，會直接讀 `chars/pets/<物種>/out/` 裡**最新匯出**的美術，不用重新打包。
- 只拿到這個資料夾（解壓縮後）也可以開：打開 `index.html` 就會用 `assets/pets/` 裡打包好的美術。用 file:// 開的時候瀏覽器不讓讀像素，所以不同物種不會上色，只會加名字標籤。
- 要把最新美術打包進來：`bash pettest/tools/sync_assets.sh`。
- 目前所有物種都先借用**西施犬**的圖：會依物種換顏色，並加上名字標籤。
  - 美術組在 `chars/pets/<物種 id 或別名>/out/` 匯出 `anchors.json` 和圖片之後，會自動改用那個物種自己的圖。

## 第一期做了什麼

1. **救援關**：打開 10 個籠子，打完 3 波小怪。
   - 救下的 10 隻先住馬廄（候補名冊），可以在「櫃檯」收留到後院。
   - 蜜糖媽媽另外送 1 隻：你選物種，是藍色寶寶，♡3，會自動設為出戰。
2. **收容所**：寵物會在院子裡走動、睡覺、發呆。開心的時候頭上冒愛心，寶寶畫得比較小。
   - **照顧**：摸摸（頭、下巴、肚子、背，有最喜歡和最討厭的地方）、乾乾、剩食麵包、特製零食、梳毛洗澡、小遊戲（簡化版）、散步（30 分、2 小時、6 小時），還有取名。
   - **需求條**：會照真實時間下降；每天 05:00（台北）結算；每天的全額次數有上限；超過 20 小時沒來會觸發重逢；把時間往回調不會有進度。
   - **好感**：照公式 2.12 計算（位階倍率 × 各種加成，加成最多 +60%）。
   - **洗技能／洗屬性（P2b）**：櫃檯「🎲 洗技能／洗屬性」→ 選寶寶 → 直接洗；名冊每列和照顧面板也有大按鈕。洗 1 格：金幣 1,500／5,000／12,000／25,000＋磁片 1，或剩食麵包 10／25／60／120（不用磁片）；洗屬性：金幣 1,000／2,500／6,500／13,000 或麵包 7／15／25／50。剛出生就能洗。
   - **寶寶養成**：技能（#1～71，有權重、位階限制、分類上限、性格加成，洗技能 6 次保底 3 選 1）、副屬性、洗屬性（6 次保底）、升階（50%／20%／8%，有保底）、等級和經驗。
   - **其他**：放他出去闖闖（10 秒內可以叫回來）。
   - **櫃檯**：指定認養、門口徘徊的動物、候補名冊、材料、圖鑑。
   - **投靠**：每天 05:00 依名聲等級擲一次；位階機率依幸運點計算（2.11）。
3. **配對**（P2：不分性別）：小屋要同物種、兩隻都 ♡3 以上、寶寶出生滿 3 天、不是一家人；成功時小屋出現育兒籃。
   - 懷孕機率 = 基本＋好感＋同住天數＋默契＋一起玩，再乘上位階倍率，上限 70%。
   - 每天 05:00 擲一次，出現育兒籃之後至少 12 小時才出生；冷卻算在小屋上。
   - 一胎幾隻、寶寶位階、性格、資質、星痕、家傳血脈、代數都照 P2.4。
   - 每天最多出生 6 隻，育兒室最多 20 隻。
4. **測試場**（一般／王戰／救援）：
   - **主角**：使用苦達斯的圖。
   - **小怪**：蜘蛛、斧兵、弓箭手（遠程），還有王「寶石劫掠者」。
   - **寵物**：跟在主角後面。普攻依位階和資質計算，技能自動施放，畫面左上會列出冷卻。
   - **寵物受擊**：被打到只會閉眼，沒有血量，也不會倒下。
   - **吱吱變鼠術 #32**：老鼠被打倒必掉麵包（紫 1、粉 1＋50%、橘 2）。
   - **小豬存錢筒 #44**：小豬被打倒必掉麵包（粉 2、橘 3），金幣 ×2。
   - **對王**：王只會變身 5 秒，一場 1 次（橘色寶寶 2 次，第二次 3 秒）。所有控制技共用 20 秒冷卻；冷卻中放到王身上只有動畫。
   - **額外糧食上限**：寵物每場額外掉的糧食最多 5 個；每天超過 40 個之後減半。
   - **食物槽**：3 格，滿了之後撿到的會變成「剩食麵包」存起來。
   - **已做效果的技能**：元素 1～7、突擊、飛彈、應援、祝福、減益、嘲諷、泡泡、起來呀、黏黏膠、一起跳舞、交換位置、香蕉皮、抖口袋、毛線、縮小燈、搖籃曲、大聲汪、躲貓貓、小豬、泡泡飄、咕咕雞炸彈、骨頭、順手牽羊、平底鍋、雪球、巨大化、加油便當、狐火分身、招財大爆擊、各物種固有能力和被動技能。
   - **還沒做效果的技能**：#26、28、41、57、60、62、65、70。在面板裡會標示「還沒做」。
   - **戰鬥結束**：會結算金幣、麵包、寵物經驗，並計算寵物的傷害佔比。

## 第二期（P2）做了什麼

1. **櫃檯每個選項都有頭像**（櫃檯、委託、圖鑑、認養、徘徊、名冊、材料、禮物、出戰、小屋）。
2. **沒有性別**：配對只要同物種＋♡3，結果是「育兒籃」。
3. **遺傳**：星痕（0／1／2）、家傳血脈（70% 沿用、父母同技 50% 進第一格）、資質雙擲、第 N 代（升紫 +0.5%／代，最多 6 代）、性格 60% 繼承。
4. **星彩**（色違）：1/256（名聲 Lv5、Lv9 各 +50%），每個物種一組換色＋閃光，能力 ×1.10；幸運石讓下一個育兒籃突變 ×3。
5. **救援只在委託**：r1～r4，各一次；出戰選單不再有救援關。
6. **面板**：全部都有 ✕、◀ 返回、Esc、點外面關、不蓋住按鈕列、再按一次按鈕關。
7. **便便**：上限 20、至少 24 小時才滿、熊 ×2＋一大坨、浣熊搬到堆肥坑、一鍵打掃（麵包、星光碎片、幸運石、裝備）、10 坨起好臭泡泡、15 坨起蒼蠅、角色吐槽。
8. **對白**：`pet/pet_lines.js`，寵物 153 句、角色 49 句，共 202 句；依性格輪替、不連續重複；小秘密只用角色口吻暗示。

## 正式版一定要拿掉開發者介面

- **開發者程式放在哪**：全部在 `dev/` 資料夾。`index.html` 裡載入它們的地方用 `<!--DEV-->…<!--/DEV-->` 包起來；`dev/` 裡的 js 也用 `/*DEV*/…/*/DEV*/` 包起來。
- **正式程式**：`pet/*.js` 裡沒有任何開發者字樣。
- **做正式版**：`bash pettest/tools/build_release.sh [輸出資料夾]`。它會把開發者區塊和 `dev/` 拿掉，打包完自動跑檢查。
- **發布前檢查**：`tools/check_no_dev.sh [資料夾…]`，加上 `--runtime` 會用無頭 Chrome 實際打開來測。
  - 不帶參數時，會檢查 `dist_web`、`build/gh-pages`、`exe/web` 和手機的 assets。
  - 通過會印「正式版無開發者入口：通過」；沒通過會 exit 1，並列出位置。
